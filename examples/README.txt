Example gallery
===============

A collection of short, self-contained examples showing how to build,
inspect, invert and combine :mod:`ftsdata` cubes.

Every example is a runnable Python script.  The figures on each page are
generated when the documentation is built, so they always reflect the
current version of the code.  Use the "Download Python source code" and
"Download Jupyter notebook" links at the bottom of a page to get the
corresponding file and experiment with it locally.
